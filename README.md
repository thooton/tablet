# tablet

Apps for the reMarkable 2, run by [AppLoad](https://github.com/asivery/rm-appload).

| App | What it is |
|---|---|
| [Spanish Reader](spanish-stories/) | Graded Spanish stories; tap a word for its English. |
| [Updater](updater/) | Installs and updates the apps here from the [latest release](https://github.com/thooton/tablet/releases/tag/latest). |

Install the Updater once by hand (see [updater/package/README.txt](updater/package/README.txt));
it installs everything else, itself included, from then on.
