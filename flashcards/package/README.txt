Flashcards for reMarkable
=========================

Anki's desktop window, in black and white: the deck list, a deck's
overview, the reviewer and the deck's options. The decks are the ones
Flashcards on the phone studies, synced through the Delta command center;
a triangle marks New, a square Learning and a circle To Review, where Anki
uses blue, red and green.

This folder lives on the tablet at /home/root/flashcards:

  install.sh     installs (or updates) Flashcards in AppLoad
  uninstall.sh   removes it again (--purge also removes its cards)
  app/           the app itself (install.sh copies it into AppLoad)

Install it with the Updater (GET beside Flashcards), then tap Reload in
AppLoad. The first time it opens it shows a pairing code: type it on the
Tablet page of the Delta website, and the decks arrive.

The cards are kept in /home/root/.local/share/flashcards.
